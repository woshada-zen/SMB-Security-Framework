## 🚩 10 Warning Signs of Phishing Emails

### ✓ Before You Click, Check These:

| Red Flag | What to Look For | Example |
|----------|------------------|---------|
| **1. Suspicious Sender** | Email address doesn't match sender name | "Microsoft" <phishing@gmail.com> |
| **2. Misspelled Domain** | Similar but wrong domain | `micr0soft.com` (zero not 'o')<br>`compnay.com` (not company.com) |
| **3. Generic Greeting** | "Dear Customer" instead of your name | Real companies know your name |
| **4. Urgent Language** | Threats or panic-inducing | "Account closes in 24 hours!"<br>"Immediate action required!" |
| **5. Too Good to Be True** | Unexpected prizes or refunds | "You've won £5,000!"<br>"Unclaimed tax refund" |
| **6. Suspicious Links** | Hover to reveal real destination | Text: microsoft.com<br>URL: phishing-site.com |
| **7. Unexpected Attachments** | You weren't expecting a file | Invoice.zip<br>Resume.exe |
| **8. Poor Grammar** | Spelling errors, awkward phrasing | "Your account have been suspended" |
| **9. Requests for Passwords** | Legitimate companies NEVER ask | "Verify password by replying"<br>"Confirm login credentials" |
| **10. Unusual Requests** | Colleague acting out of character | CEO asking for gift cards<br>Manager: "Wire £50k urgently" |

---

## ✅ What To Do

### If You Receive Suspicious Email:

**STOP** → Don't click links or open attachments
**THINK** → Check for red flags above
**REPORT** → Use "Report Phishing" button in Outlook

### How to Report Phishing:
1. Select suspicious email
2. Click **"Report Message"** > **"Phishing"**
3. Email automatically quarantined and sent to IT Security

**Or** forward to: **security@company.com**

**Email claims to be from colleague/CEO:**
→ Call them using company directory (don't use number in email)

**Email claims to be from Microsoft/vendor:**
→ Contact IT Help Desk: **[PHONE NUMBER]**

**30-second verification call can save thousands**
