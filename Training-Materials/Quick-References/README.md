## Completed Guides

### 01: Phishing Red Flags Checklist ✓
**Purpose:** Help employees identify phishing emails before clicking
**Key Content:**
- 10 red flags (suspicious sender, urgency, bad links, etc.)
- What to do if suspicious (STOP-THINK-REPORT)
- What to do if already clicked (based on severity)
- Verification process (call to confirm)
- Contact numbers for reporting

**Distribution:**
- Print on color paper, laminate, place at every desk
- Email to all employees quarterly (refresher)
- Include in new hire welcome packet

---

### 02: Data Classification Quick Guide ✓
**Purpose:** Help employees choose correct sensitivity label
**Key Content:**
- 5 classification levels with examples (Public to Restricted)
- Decision tree for classification
- Email sharing rules by classification
- How to apply labels in Microsoft 365 (Outlook, Word, OneDrive)
- Examples by department (Finance, HR, Sales, IT)
- FAQs

**Distribution:**
- Print 2-page guide, laminate, desk reference
- Digital version on intranet
- Include in onboarding training

---

### 03: MFA Enrollment Guide ✓
**Purpose:** Step-by-step instructions for enrolling in multi-factor authentication
**Key Content:**
- 5-minute quick start (3 steps)
- Download Microsoft Authenticator (iOS/Android)
- Enroll at aka.ms/mfasetup with QR code
- Add backup SMS method
- Test setup
- Daily usage and troubleshooting
- Why MFA matters (99.9% protection)

**Distribution:**
- Email to all new hires (within first day)
- Print for in-person enrollment assistance
- Post on intranet with screenshots
- Include in MFA rollout communications

## Design Guidelines

### Layout
- **Font:** Arial or Calibri (easy to read)
- **Size:** Minimum 10pt body, 14pt+ headings
- **Colors:** Company brand colors
- **Logo:** Company logo in header
- **White Space:** Adequate margins, not cluttered

### Accessibility
- High contrast (black text on white/light background)
- Avoid red/green only distinctions (colorblind-friendly)
- Sans-serif fonts (better readability)
- Bulleted lists (easier to scan)

### Print Specifications
- **A4 Guide:** 210mm x 297mm, PDF for printing
- **Wallet Card:** 85mm x 55mm (standard business card size)
- **Desk Tent:** 210mm x 99mm folded (A4 landscape, fold in half)
- **Paper:** 200gsm cardstock (laminate for durability)

## Distribution Strategy

### Physical Distribution
- **New Hire Kit:** All 8 guides printed, placed in welcome folder
- **Desk Placement:** Phishing checklist + Data classification at every desk
- **Laminated Cards:** Incident reporting wallet card for all employees
- **High-Traffic Areas:** Posters in break rooms, printer areas

### Digital Distribution
- **Intranet Security Page:** All guides downloadable as PDF
- **Email Campaigns:** One guide per month (rotating topics)
- **Teams/Slack:** Pin guides in company-wide channel
- **Mobile Access:** Mobile-friendly versions (responsive web page)

### Replenishment
- **Replacement Requests:** Via IT ticketing system
- **Quarterly Refresh:** Replace damaged/outdated guides
- **Update Triggers:** Policy changes, new threats, user feedback
